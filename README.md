# سواعد للإشراف الهندسي

تطبيق **سواعد للاستشارات الهندسية** لإدارة مشاريع الإشراف الهندسي على تنفيذ المباني. منظومة واحدة تعمل على ثلاث واجهات:

- **التطبيق الميداني** لمهندسي الإشراف (Android وiOS والمتصفح): إدخال سريع من الموقع، ويعمل **دون إنترنت**.
- **لوحة الإدارة** لمدير قسم الإشراف ومديري المشاريع (اللابتوب: PWA أو برنامج Windows/macOS).
- **خادم Supabase** واحد: كل عمل يُسجَّل في الموقع يحدّث المنظومة كلها لحظياً، والصلاحيات تفرضها قاعدة البيانات نفسها.

الواجهة عربية بالكامل من اليمين لليسار، وتعرض التواريخ بالميلادي والهجري (أم القرى)، وتلتزم بهوية سواعد.

## التقنية

| الطبقة | الاختيار |
|---|---|
| الواجهة | Next.js 16 (App Router, static export) + TypeScript + Tailwind 4، كتطبيق PWA مع Service Worker |
| التخزين المحلي | IndexedDB (Dexie): نسخة من بيانات مشاريع المستخدم، وطابور مزامنة، وتعارضات، وصور قبل الرفع |
| الجوال | Capacitor 8 (Android وiOS) بنفس الكود: الكاميرا، والموقع، والإشعارات |
| سطح المكتب | تثبيت الـ PWA من المتصفح، أو Tauri 2 لملف تثبيت (`.msi` و`.exe` و`.dmg`) |
| الخادم | Supabase: PostgreSQL مع RLS على كل جدول، وAuth، وStorage، وRealtime، وEdge Functions، وpg_cron |
| التقارير | PDF عربي يُولَّد في الخادم (pdf-lib + fontkit + Unicode Bidi) بخط IBM Plex Sans Arabic |
| الإشعارات | Web Push (VAPID)، وFCM (أندرويد)، وAPNs (iOS)، وملخص أسبوعي بالبريد (Resend) |

## التشغيل محلياً

```bash
npm ci
supabase start                                   # قاعدة البيانات + المهاجرات + البذور
cp .env.local.example .env.local                 # عنوان Supabase المحلي ومفتاحه
export SUPABASE_DB_URL=postgresql://postgres:postgres@127.0.0.1:54322/postgres
export SUPABASE_URL=http://127.0.0.1:54321 SUPABASE_SERVICE_ROLE_KEY=<من supabase status>
npm run import -- scripts/fixtures/sample-export.json   # أو ملف التصدير الحقيقي
npx tsx scripts/dev-seed-users.ts                # حسابات تجريبية (للتطوير فقط)
npm run dev                                       # http://localhost:3000
```

الحسابات التجريبية، وكلمة مرورها كلها `Sawaed#2026`:

|---|---|

| `dept@sawaed.test` | مدير قسم الإشراف |
| `fahad@sawaed.sa` | مدير مشروع «فيلا الياسمين» |
| `reem@sawaed.test` | مهندسة مقيمة في «فيلا الياسمين»، ومهندسة زيارات في «عمارة النرجس» |

## الاختبارات

| الأمر | ما يثبته |
|---|---|
| `npm run test:db` | **153** اختباراً في PostgreSQL. RLS: مدير المشروع لا يقرأ أي سجل من مشروع غير مكلّف به، والمهندس لا يحذف، والتكليف المنتهي يسحب الصلاحية، ولا أحد يرفع صلاحيته بنفسه. المنطق: النسبة من أوزان المراحل، ودرجة المخاطر، وحالات «متأخر»، والأسبوع من السبت إلى الجمعة، والتحديث المتسلسل، والإشعارات، والتقرير الأسبوعي |
| `npm test` | **38** اختبار وحدات: منطق المجال، ولوحة القيادة، وقائمة «يحتاج متابعة الآن»، وتحويل ملف الاستيراد، وضغط الصور، ومحرك النص العربي في PDF |
| `SUPABASE_IT=1 npx vitest run src/lib/sync.integration.test.ts` | **6** اختبارات لمحرك المزامنة على Supabase حقيقي: الطابور دون اتصال، والتعارض بين جهازين، والحذف المرفوض، والحذف من الخادم، وسحب الصلاحية |
| `npm run test:e2e` | **سيناريو القبول الكامل**: مهندس دون إنترنت يسجّل تحديثاً بصور وطلب فحص ومخالفة جسيمة، ثم بعد الاتصال تظهر في لوحة مدير القسم خلال ثانيتين تقريباً، ويُرسل الإشعار، ويتضمنها التقرير الأسبوعي PDF. ومعه فحص كل الشاشات على عرض 360px لكل دور |

Lighthouse لصفحة الدخول: PWA 100، وإمكانية الوصول 100، وأفضل الممارسات 100.

## هيكل المستودع

```
src/app/            الشاشات (لوحة القيادة، المشاريع، المشروع، الإدخال، التسكين، التقارير، التنبيهات، المزامنة، الإدارة)
src/components/     مكوّنات الواجهة (النموذج العام، الصور، التوقيع، الرسوم، عرض التقرير)
src/lib/            المنطق: domain, analytics, db (Dexie), sync, mutations, session, forms
supabase/migrations المخطط وRLS والمنطق والقرارات (8 مهاجرات)
supabase/functions  render-pdf · dispatch-push · invite-user · weekly-email (+ _shared: PDF عربي، إشعارات)
supabase/sql-tests  اختبارات قاعدة البيانات
scripts/            الاستيراد، والحسابات التجريبية، والأيقونات، وService Worker
e2e/                اختبارات Playwright
android/ ios/       مشروعا Capacitor
src-tauri/          تطبيق سطح المكتب
.github/workflows   CI، وإصدار التطبيقات، ونشر الخادم
```

المنصة القديمة (`index.html` و`dashboard.html`) باقية كما هي حتى يكتمل الانتقال.
