# سواعد للإشراف الهندسي

تطبيق لإدارة مشاريع الإشراف الهندسي لشركة سواعد للاستشارات الهندسية.

- `index.html`, `dashboard.html` — المنصة الحالية (Firebase).
- `supabase/` — الخادم الجديد: المخطط وسياسات RLS والمنطق والاختبارات.
- `docs/01-database-schema.md` — مخطط قاعدة البيانات والصلاحيات للمراجعة.

## تشغيل اختبارات قاعدة البيانات

```bash
supabase/sql-tests/run_local.sh
```
