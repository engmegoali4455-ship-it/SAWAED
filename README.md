# سواعد — تطبيقات الإشراف الهندسي

| الصفحة | الوصف |
|---|---|
| `projects.html` | **إدارة مشاريع الإشراف — الرقابة المركزية**: لوحة متابعة كل المشاريع، نسبة الأعمال محسوبة من أوزان مراحل الرقابة الـ11، الزيارات، طلبات الفحص، المستخلصات، المراسلات، الملاحظات والمخالفات، واستيراد/تصدير Excel بنفس أعمدة ملف المتابعة. |
| `index.html` | سجل الملاحظات الميدانية (Snag list) والأعمال الجارية. |
| `dashboard.html` | لوحة تحكم مدير الفريق. |

البيانات تُحفظ على Firebase (مجموعات `sv_projects` و `sv_records` و `meta/sv_stages`) وتتزامن بين كل الأجهزة، مع نسخة محلية على الجهاز عند انقطاع الاتصال. كلمة الدخول هي نفس كلمة سر الفريق.
