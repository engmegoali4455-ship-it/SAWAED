# دليل التشغيل

## نقل البيانات من المنصة الحالية

1. **صدّر البيانات من المنصة الحالية:** الإعدادات ← «تصدير كل البيانات» (JSON بالمفاتيح `projects`, `updates`, `risks`, `inspections`, `permits`, `invoices`, `works`, `meetings`, `violations`, `engineers`, `assignments`, `stages`, `deptManagers`).
2. **جرّب أولاً دون حفظ:**
   ```bash
   npm run import -- export.json --dry-run
   ```
   يطبع عدد كل نوع، والسجلات المرفوضة وسبب كل منها، والتنبيهات. ويحفظ ذلك في `import-report.json`.
3. **صحّح ما يلزم في الملف**، ثم استورد:
   ```bash
   SUPABASE_DB_URL=... SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... npm run import -- export.json
   ```
   - كل الإدراج في **معاملة واحدة**: إما يُستورد كل شيء أو لا شيء.
   - **إعادة التشغيل آمنة**، لأن الإدراج يحدّث السجل الموجود بنفس المعرّف.
   - **المعرّفات والعلاقات تبقى كما هي.**
   - الصور المضمّنة في الملف (data URL) أو بروابط تُرفع إلى Storage.
4. **أوزان المراحل:**
   - إن لم يكن مجموعها 100 يتوقف الاستيراد. صحّح الأوزان في الملف، أو أضف `--normalize-weights` لتوزيعها نسبياً.
   - المراحل التي يدل اسمها على صب (أساسات، ميدات، هيكل، سقف) تُعلَّم «قبل الصب» تلقائياً، ويمكن تعديل ذلك من الإدارة ← المراحل.
5. **التحويل والرفض:**
   - **أسماء الحقول:** يقبل الاستيراد الصيغ المختلفة (`projectNo`, `project_no`, `number`…).
   - **القيم العربية:** تُحوَّل إلى رموزها («استمرار»، «مدير مشروع الإشراف»، «جسيمة»…).
   - **التواريخ:** يقبل `2026-10-18` و`18/10/2026` والأرقام العربية وطوابع Firestore.
   - **ما يُرفض مع ذكر السبب:** السجل بلا مشروع، أو المرتبط بمشروع أو مهندس غير موجود، أو بقيمة خارج النطاق.

## الحسابات والصلاحيات

1. **الدعوة:** مدير النظام يدعو المستخدم من الإدارة ← المستخدمون ← «إرسال دعوة»، فيصله بريد لتعيين كلمة المرور.
2. **الربط:** من الشاشة نفسها، اكتب البريد واختر المهندس أو مدير القسم ثم اضغط «ربط». يظهر بريد المهندس من ملف التصدير بجانب اسمه للمطابقة.
3. **صلاحية المشروع:** تأتي من **التسكين** وحده:
   - التكليف بدور «مدير مشروع الإشراف» يمنح صلاحية مدير المشروع.
   - التكليف بأي دور آخر يمنح صلاحية المهندس.
   - تاريخ «إلى» الماضي يسحب الصلاحية فوراً، ويُمسح المشروع من جهاز المهندس عند المزامنة التالية.
4. **المالك أو المقاول:** يُضاف من الإدارة ← المالك والمقاول. يرى التقارير المعتمدة، والمخالفات، وطلبات الفحص، ويرد عليها فقط.
5. **إيقاف حساب:** الإدارة ← المستخدمون ← «إيقاف»، فتتوقف كل صلاحياته فوراً.

## المهام المجدولة (pg_cron، بتوقيت UTC)

| المهمة | الموعد (الرياض) | ماذا تفعل |
|---|---|---|
| `daily-digest` | يومياً 7:00 | بنود اجتماعات متأخرة، وتراخيص تنتهي بعد 30 أو 7 أيام أو انتهت، وتحديثات متأخرة، ومخالفات تجاوزت المهلة. إشعار واحد لكل مستخدم |
| `weekly-reports` | الخميس 12:00 | مسودة تقرير لكل مشروع نشط (أسبوع السبت إلى الجمعة)، ولا تمس المعتمد |
| `weekly-email` | الخميس 14:00 | ملخص المحفظة بالبريد لمديري القسم ومدير النظام |
| `push-sweep` | كل دقيقة | احتياط لإرسال أي إشعار لم يُرسل |

- **للتشغيل يدوياً:** `select app.run_daily_digest();` أو `select app.generate_weekly_reports();`
- **لمراجعة التنفيذ:** `select * from cron.job_run_details order by start_time desc limit 20;`

## سير التقرير الأسبوعي

1. يُولَّد التقرير الخميس، أو يدوياً من التقارير ← «توليد الآن».
2. يراجعه مدير المشروع، ويضيف ملاحظاته، ويضغط «تحديث البيانات» إن سُجّل جديد.
3. **اعتماد:** تُجمَّد لقطة التقرير بعده ولا تتغير.
4. **تنزيل PDF**، ثم **إرسال للمالك** إن رغب (يصله إشعار ويرى التقرير في بوابته).

## حل المشكلات

| العَرَض | السبب والحل |
|---|---|
| شارة «بانتظار N» لا تختفي | لا اتصال، أو الخادم رفض عملية: افتح المزامنة، وستظهر «عمليات لم تُقبل» بالسبب (صلاحية أو قيمة) مع «إعادة المحاولة» أو «تجاهل» |
| «تعارض» | سجل عُدّل من جهازين. افتح المزامنة واختر النسخة المعتمدة |
| لوحة القيادة لا تتحدث لحظياً | تأكد أن كل الجداول منشورة: `select tablename from pg_publication_tables where pubname='supabase_realtime';` (المهاجرة 8) |
| لا تصل الإشعارات | تحقّق من صفّي `push_endpoint` و`push_secret` في `app_settings`، ومن أسرار VAPID/FCM/APNs، ومن سجل الدالة `dispatch-push`. `select count(*) from notifications where pushed_at is null` يجب أن يقترب من صفر |
| PDF يفشل | سجل `render-pdf`. الخطوط مضمّنة عبر `static_files` في `config.toml` |
| تغيير أوزان المراحل | الإدارة ← المراحل والأوزان (مدير النظام). الحفظ ذرّي والمجموع يجب أن يكون 100، ولا تُحذف مرحلة فيها مشاريع حالياً |

## النسخ الاحتياطي

- **النسخ اليومية:** النسخ اليومية التلقائية في Supabase (Pro فأعلى)، أو فعّل Point-in-Time Recovery.
- **سجل التدقيق:** يحفظ القيمة قبل كل تعديل وحذف وبعده، ويُستعاد منه أي سجل حُذف خطأً.
